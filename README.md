# AI Competitor Monitoring System

An AI-powered competitor website monitoring platform built with FastAPI.

## Features

- Website Monitoring
- Automatic Scheduled Scans
- HTML Change Detection
- Screenshot Capture
- AI Change Summaries
- Dashboard Analytics
- Severity Detection
- Recent Activity Feed

## Tech Stack

- FastAPI
- SQLAlchemy
- SQLite
- Playwright
- OpenAI
- APScheduler
- Jinja2
- HTML/CSS

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/ai-competitor-monitor.git

cd ai-competitor-monitor

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

uvicorn app.main:app --reload
```
